# Torolalana hanaovana APK TONONKIRA APTM

1. Ampidiro ao amin'ny GitHub repository `TONONKIRA-APTM` ny votoatin'ity projet ity.
2. Sokafy ao amin'ny Android Studio (JDK 17 sy Android SDK 35).
3. Ataovy Sync Gradle.
4. Safidio Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Rehefa vita, alao ny `app/build/outputs/apk/debug/app-debug.apk`.

Tsy APK efa vita ity ZIP ity. Source code izy, ka mila build sy test aloha.
